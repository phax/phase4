# Security Policy

## Supported versions

Security fixes are provided for the following versions of phase4:

| Version | Supported |
| ------- | --------- |
| 5.x     | Yes (once released) |
| 4.9.x   | Yes - the latest 4.x line |
| < 4.9   | No |

When a new 4.x minor version is released, it replaces 4.9.x as the supported 4.x line.

## Reporting a vulnerability

Please do **not** report security vulnerabilities via public GitHub issues, discussions or pull requests.

Report them privately via GitHub instead:
[Report a vulnerability](https://github.com/phax/phase4/security/advisories/new)
(tab "Security" of the repository, button "Report a vulnerability").

Please include:

* the affected phase4 version(s) and AS4 profile(s)
* a description of the issue and its impact
* steps to reproduce, ideally a minimal message or test case
* any known workaround

You will receive an answer as soon as possible.
After the issue is confirmed and fixed, a release is made and the vulnerability is disclosed via a GitHub Security Advisory.

## Hardening

See the Wiki page [Security Hardening](https://github.com/phax/phase4/wiki/Security-Hardening) for recommendations on how to operate phase4 securely.
